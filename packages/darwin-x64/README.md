# @whatsup-cli/darwin-x64

The macOS x86_64 (Intel) binary of [whatsup](https://github.com/GeekyAsif786/whatsup) (Rust target `x86_64-apple-darwin`).

Don't install this package directly: install [`whatsup-cli`](https://www.npmjs.com/package/whatsup-cli),
which picks the right binary for your platform.

```sh
npx whatsup-cli
```
