# @whatsup-cli/linux-arm64

The Linux arm64 (glibc) binary of [whatsup](https://github.com/GeekyAsif786/whatsup) (Rust target `aarch64-unknown-linux-gnu`).

Don't install this package directly: install [`whatsup-cli`](https://www.npmjs.com/package/whatsup-cli),
which picks the right binary for your platform.

```sh
npx whatsup-cli
```
