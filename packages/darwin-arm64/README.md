# @whatsup-cli/darwin-arm64

The macOS arm64 (Apple silicon) binary of [whatsup](https://github.com/GeekyAsif786/whatsup) (Rust target `aarch64-apple-darwin`).

Don't install this package directly: install [`whatsup-cli`](https://www.npmjs.com/package/whatsup-cli),
which picks the right binary for your platform.

```sh
npx whatsup-cli
```
