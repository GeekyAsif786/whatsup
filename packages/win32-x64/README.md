# @whatsup-cli/win32-x64

The Windows x86_64 binary of [whatsup](https://github.com/GeekyAsif786/whatsup) (Rust target `x86_64-pc-windows-msvc`).

Don't install this package directly: install [`whatsup-cli`](https://www.npmjs.com/package/whatsup-cli),
which picks the right binary for your platform.

```sh
npx whatsup-cli
```
