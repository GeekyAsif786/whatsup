# @whatsup-cli/linux-x64

The Linux x86_64 (glibc) binary of [whatsup](https://github.com/GeekyAsif786/whatsup) (Rust target `x86_64-unknown-linux-gnu`).

Don't install this package directly: install [`whatsup-cli`](https://www.npmjs.com/package/whatsup-cli),
which picks the right binary for your platform.

```sh
npx whatsup-cli
```
